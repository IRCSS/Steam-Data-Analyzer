# Steam data analyzer

This is a series of python notebook that works on a specific type of data scrapped from steam public API to get a bunch of info. The project is setup with UV, use it as well for best exprience. Also I am using VS Code for it as well.

The data set itself is not in here, since its like 3 GB (140k games). You can either scrapped the data using this repo: https://github.com/IRCSS/Steam-Games-Scraper which is a fork of repo by Fronkon games, or download the latest version of the scrapped data which the repo owner maintains: https://www.kaggle.com/datasets/fronkongames/steam-games-dataset . The only thing my fork has on top, it uses the dataset the repo generates to pull some info that is not in the original data set, mostly around whether the game uses AI or not.
